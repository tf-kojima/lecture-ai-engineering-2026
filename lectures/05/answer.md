- やったこと（変更したファイル・設定・処理、または設計した取得方法）：
  検索結果に、同じ資料の前後1ページの本文を付けて返すように改良した。
  - app/retrieval.py：add_neighbor_pages() を追加。load_pages() のページの並び順を使い、同じ document_id の中で前後のページを探す（別の資料はまたがない）。
    同じページは1回だけ返し、検索で見つかったページ（role: hit）を、前後として足したページ（role: neighbor、neighbor_of: 隣のページID）より優先する。
    並びは、検索の順位ごとに「前のページ → 見つかったページ → 次のページ」。search_with_neighbors() で search() の結果に適用する。
  - app/tools.py：search_materials が search_with_neighbors() を使うように変更。
  - app/config.py：前後に付けるページ数を RAG_NEIGHBOR_PAGES（環境変数 AIE_RAG_NEIGHBORS、既定 0）で切り替えられるようにした。
    既定は 0 で従来どおりなので、コードを戻さずに変更前後を比べられる。Graph は元の search() を使うので影響しない。
  - 索引は変えていないので、再作成はしていない。uv run pytest -q は 21 passed。
